# e-plantShopping

## Overview
e-plantShopping is a shopping cart application for Paradise Nursery, an online plant shop that offers a variety of house plants. Users can browse different plants, view details, add items to the cart, and manage their shopping cart dynamically.

## Features
- **Landing Page:** A welcome page with a button linking to the product listing page.
- **Navigation Bar:** Links to the landing page, product listing, and shopping cart pages.
- **Product Listing:** Cards for each plant showing images, name, description, cost, and an "Add to Cart" button.
- **Plant Sections:** Categorized sections such as "Aromatic Plants" and "Medicinal Plants."
- **Shopping Cart:** Displays products in the cart with quantity controls, total cost, and delete options.
- **Dynamic Cart:** Updates cart quantity and total cost as users interact with items.
- **Continue Shopping & Checkout:** Buttons for navigating and completing purchases.

## Technologies Used
- React
- Redux (for state management)
- CSS
- JavaScript
